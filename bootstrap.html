CÓMO INCLUIR BOOTSTRAP EN HTML

Práctica 10: Integración de Bootstrap

1. Teoría Básica

Bootstrap es el framework CSS más popular para construir sitios web responsivos y modernos rápidamente. Se puede integrar a través de CDN (Content Delivery Network):

  • Etiqueta <link> en <head>: Carga la hoja de estilos CSS de Bootstrap desde un servidor remoto.
  • Etiqueta <script> antes de </body>: Carga el JavaScript de Bootstrap para componentes interactivos (módulos, desplegables, carruseles).
  • Sistema de rejilla (Grid): Utiliza clases como container, row y col para maquetar fácilmente.
  • Componentes reutilizables: Incluye botones, tarjetas, alertas y barras de navegación prediseñadas.
