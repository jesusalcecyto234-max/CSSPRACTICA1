Práctica 1: Modelo de Caja (Box Model)

1. Teoría Básica

El modelo de caja es la forma en que CSS maneja el tamaño y diseño de todos los elementos HTML. Cada elemento es considerado una caja rectangular compuesta por cuatro partes:

  • Contenido: Es el texto, imagen o elemento real que está dentro de la caja.
  • Padding (Relleno): Es el espacio entre el contenido y el borde de la caja.
  • Border (Borde): Es la línea que rodea al relleno y al contenido.
  • Margin (Margen): Es el espacio exterior que separa a esta caja de otros elementos.
