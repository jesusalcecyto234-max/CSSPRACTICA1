FLEXBOX EN CSS

Práctica 7: Flexbox en CSS

1. Teoría Básica

Flexbox (Flexible Box Layout) es un modelo de diseño unidimensional pensado para distribuir espacio y alinear elementos en filas o columnas de forma flexible. Propiedades clave:

  • display: flex; Activa el contenedor flexible.
  • flex-direction: Define la dirección de los elementos (row, column, row-reverse, column-reverse).
  • justify-content: Alinea los elementos en el eje principal (flex-start, center, flex-end, space-between, space-around).
  • align-items: Alinea los elementos en el eje cruzado (stretch, center, flex-start, flex-end).
  • flex-wrap: Controla si los elementos pasan a una nueva línea si no caben (nowrap, wrap).
