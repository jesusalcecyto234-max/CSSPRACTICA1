Práctica 8: CSS Grid Layout

1. Teoría Básica

CSS Grid Layout es un sistema de diseño bidimensional (filas y columnas al mismo tiempo) para crear retículas avanzadas. Sus propiedades principales son:

  • display: grid; Define un contenedor de tipo rejilla o retícula.
  • grid-template-columns: Define la cantidad y ancho de las columnas (px, %, fr).
  • grid-template-rows: Define la cantidad y alto de las filas.
  • gap: Establece la separación o espacio entre celdas (filas y columnas).
  • grid-column / grid-row: Permite expandir o posicionar una celda a lo largo de varias columnas o filas.
