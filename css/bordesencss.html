BORDES EN CSS

Práctica 2: Bordes en CSS

1. Teoría Básica

Los bordes en CSS permiten delimitar el contorno de los elementos HTML. Se pueden personalizar mediante tres propiedades principales:

  • border-style: Define el estilo de la línea (sólida, punteada, guiones, doble, etc.).
  • border-width: Define el grosor del borde (px, em, thin, medium, thick).
  • border-color: Define el color del borde (nombres, HEX, RGB).
  • border-radius: Permite redondear las esquinas de los bordes.
